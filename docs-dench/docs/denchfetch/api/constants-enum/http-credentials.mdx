# HTTPCredentials

## 어떤 enum인가요?

Fetch API의 `RequestInit.credentials` 값을 지정하는 문자열 enum입니다. 브라우저가 요청에 쿠키와 같은 자격 증명을 포함할지 결정합니다.

## Values

| Name | Value | Description |
| --- | --- | --- |
| `INCLUDE` | `'include'` | 교차 출처 요청을 포함한 모든 요청에 자격 증명을 포함합니다. |
| `SAME_ORIGIN` | `'same-origin'` | 동일 출처 요청에만 자격 증명을 포함합니다. |
| `OMIT` | `'omit'` | 요청에 자격 증명을 포함하지 않습니다. |

## Example

```ts
import { dench, HTTPCredentials } from 'dench-fetch';

const profile = await dench('https://api.example.com')
  .get('/profile')
  .credentials(HTTPCredentials.INCLUDE)
  .toJson();

// RequestInit: { method: 'GET', credentials: 'include', headers: {} }
```
