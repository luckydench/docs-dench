# HTTPMode

## 어떤 enum인가요?

Fetch API의 `RequestInit.mode` 값을 지정하는 문자열 enum입니다. 요청의 교차 출처 처리 방식을 설정합니다.

## Values

| Name | Value | Description |
| --- | --- | --- |
| `CORS` | `'cors'` | CORS 프로토콜을 사용하는 교차 출처 요청을 허용합니다. |
| `NO_CORS` | `'no-cors'` | 제한된 메서드와 Header로 교차 출처 요청을 보내며 opaque 응답을 반환할 수 있습니다. |
| `SAME_ORIGIN` | `'same-origin'` | 교차 출처 요청을 허용하지 않습니다. |

## Example

```ts
import { dench, HTTPMode } from 'dench-fetch';

const response = await dench('https://api.example.com')
  .get('/public-resource')
  .mode(HTTPMode.CORS)
  .toResponse();

// RequestInit: { method: 'GET', mode: 'cors' }
```
