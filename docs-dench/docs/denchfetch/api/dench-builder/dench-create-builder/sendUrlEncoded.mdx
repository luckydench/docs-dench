# sendUrlEncoded()

## 함수 시그니처

```ts
sendUrlEncoded: (data?: DenchURLSearchParams) => DenchCreateBuilder<T>
```

```ts
type DenchURLSearchParams = ConstructorParameters<typeof URLSearchParams>[0];
```

## 관련 RequestInit 및 Header 속성

```ts
{
  headers: {
    'Content-Type': 'application/x-www-form-urlencoded',
  },
  body: new URLSearchParams(data),
}
```

## 설명

전달받은 데이터를 `URLSearchParams`로 변환하고 URL 인코딩 형식의 요청 body로 설정합니다.

객체, 문자열, 문자열 튜플 배열, 기존 `URLSearchParams`처럼 `URLSearchParams` 생성자가 허용하는 값을 전달할 수 있습니다.

## 예제

```ts
import { dench } from 'dench-fetch';

const response = await dench('https://api.example.com')
  .post('/sessions')
  .sendUrlEncoded({
    username: 'dench',
    remember: 'true',
  })
  .toResponse();
```

실제 `RequestInit`과 Header는 다음과 같습니다.

```ts
{
  method: 'POST',
  headers: {
    'Content-Type': 'application/x-www-form-urlencoded',
  },
  body: new URLSearchParams('username=dench&remember=true'),
}
```

전송되는 body 문자열은 `username=dench&remember=true`입니다.

## 주의사항

- 객체 형태로 전달할 때 값은 문자열이어야 합니다.
- `data`를 생략하면 새 `URLSearchParams`를 만들지 않고 현재 빌더에 저장된 body를 그대로 사용합니다.
- 현재 실제 구현은 `post(api, data)`와 `put(api, data)`의 두 번째 인자를 저장하지 않습니다. 데이터는 `sendUrlEncoded(data)`에 직접 전달하세요.
- 이미 설정된 body와 `Content-Type` 헤더를 덮어씁니다.
