# baseURL

## 속성 시그니처

```ts
baseURL: DenchHTTPURL
```

```ts
type DenchHTTPURL =
  | `http://${string}`
  | `https://${string}`
  | `file://${string}`
  | `ftp://${string}`
  | `ws://${string}`
  | `wss://${string}`;
```

## 설명

`baseURL`은 `dench(baseURL)`에 전달한 기본 URL입니다. 클라이언트에서 생성하는 모든 요청은 이 값과 각 요청의 API 경로를 결합하여 최종 URL을 만듭니다.

## 예제

```ts
import { dench } from 'dench-fetch';

const api = dench('https://api.example.com');

console.log(api.baseURL);
// https://api.example.com
```

## 주의사항

- TypeScript에서는 프로토콜을 포함한 문자열만 `DenchHTTPURL`로 허용합니다.
- 기본 URL과 API 경로는 요청 실행 시 결합됩니다.
- 기본 URL은 `RequestInit` 속성이 아니며, `fetch()`의 첫 번째 인자인 요청 URL을 구성하는 데 사용됩니다.
