# mode()

## 함수 시그니처

```ts
mode: (mode: HTTPMode) => R
```

## 관련 RequestInit 속성

```ts
{
  mode: mode
}
```

## 설명

Fetch API의 `RequestInit.mode` 값을 설정합니다. 요청이 교차 출처 요청을 처리하는 방식을 지정합니다.

사용 가능한 값은 다음과 같습니다.

| enum | 실제 값 |
| --- | --- |
| `HTTPMode.CORS` | `'cors'` |
| `HTTPMode.NO_CORS` | `'no-cors'` |
| `HTTPMode.SAME_ORIGIN` | `'same-origin'` |

## 예제

```ts
import { dench, HTTPMode } from 'dench-fetch';

const api = dench('https://api.example.com');

const response = await api
  .get('/public')
  .mode(HTTPMode.CORS)
  .toResponse();
```

실제 `RequestInit`은 다음과 같습니다.

```ts
{
  method: 'GET',
  mode: 'cors',
}
```

## 주의사항

- `mode()`는 서버의 CORS 정책을 우회하지 않습니다.
- `HTTPMode.NO_CORS` 요청의 응답은 브라우저에서 opaque response가 될 수 있어 상태와 body 접근이 제한됩니다.
