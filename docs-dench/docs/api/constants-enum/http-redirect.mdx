# HTTPRedirect

## 어떤 enum인가요?

Fetch API의 `RequestInit.redirect` 값을 지정하는 문자열 enum입니다. 서버가 리다이렉트 응답을 반환했을 때 처리 방식을 설정합니다.

## Values

| Name | Value | Description |
| --- | --- | --- |
| `FOLLOW` | `'follow'` | 리다이렉트를 자동으로 따라갑니다. |
| `ERROR` | `'error'` | 리다이렉트 응답을 오류로 처리합니다. |
| `MANUAL` | `'manual'` | 리다이렉트를 자동으로 따라가지 않습니다. |

## Example

```ts
import { dench, HTTPRedirect } from 'dench-fetch';

const response = await dench('https://api.example.com')
  .get('/redirected-resource')
  .redirect(HTTPRedirect.MANUAL)
  .toResponse();

// RequestInit: { method: 'GET', redirect: 'manual' }
```
