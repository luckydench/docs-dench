# DenchAuthType

## 어떤 enum인가요?

`auth(token, type)`에서 `Authorization` 헤더에 사용할 인증 방식의 접두사를 지정하는 문자열 enum입니다.

`type`을 생략하면 `DenchAuthType.BEARER`가 사용됩니다. `ETC`는 접두사 없이 전달한 token을 그대로 Header 값으로 사용합니다.

## Values

| Name | Value | Description |
| --- | --- | --- |
| `ETC` | `'ETC'` | 접두사를 추가하지 않고 token을 그대로 사용합니다. |
| `BASIC` | `'Basic'` | Basic 인증 접두사를 사용합니다. |
| `BEARER` | `'Bearer'` | Bearer 토큰 인증 접두사를 사용합니다. 기본값입니다. |
| `DIGEST` | `'Digest'` | Digest 인증 접두사를 사용합니다. |
| `NEGOTIATE` | `'Negotiate'` | Negotiate 인증 접두사를 사용합니다. |
| `AWS4_HMAC_SHA256` | `'AWS4-HMAC-SHA256'` | AWS Signature Version 4 인증 접두사를 사용합니다. |
| `API_KEY` | `'ApiKey'` | ApiKey 인증 접두사를 사용합니다. |
| `TOKEN` | `'Token'` | Token 인증 접두사를 사용합니다. |
| `HMAC` | `'HMAC'` | HMAC 인증 접두사를 사용합니다. |

## Example

```ts
import { dench, DenchAuthType } from 'dench-fetch';

const response = await dench('https://api.example.com')
  .get('/secure')
  .auth('encoded-credentials', DenchAuthType.BASIC)
  .toResponse();

// Authorization: Basic encoded-credentials
```
