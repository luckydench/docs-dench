# config

## 속성 시그니처

```ts
config: DenchBaseConfig
```

```ts
interface DenchBaseConfig {
  baseURL: string;
  api: string;
  errorcallback?: (error: unknown) => void;
  URLNormalize: DenchURLNormalizeMode;
  options: DenchOptions;
}
```

## 관련 RequestInit 속성

```ts
config.options
```

`config.options`가 실제 `fetch()`의 두 번째 인자인 `RequestInit`으로 전달됩니다.

## 설명

`config`는 현재 요청 빌더가 보유한 요청 설정입니다. 최종 요청 URL을 구성하는 `baseURL`과 `api`, URL 정규화 모드, 실제 `fetch()`에 전달될 `options`를 확인할 수 있습니다.

## 예제

```ts
import { dench } from 'dench-fetch';

const request = dench('https://api.example.com')
  .get('/users/1');

console.log(request.config);
```

현재 빌더의 설정은 다음 형태입니다.

```ts
{
  baseURL: 'https://api.example.com',
  api: '/users/1',
  URLNormalize: DenchURLNormalizeMode.BOUNDARY,
  options: {
    method: 'GET',
  },
}
```

## 주의사항

- `config`는 현재 공개 속성이지만, 빌더 내부 상태를 나타냅니다.
- `config` 또는 `config.options`를 직접 수정하면 타입이 보장하는 빌더 동작을 우회할 수 있습니다. 요청 설정에는 제공되는 빌더 메서드를 사용하는 것을 권장합니다.
- `DenchBaseConfig` 타입에는 timeout과 `AbortController` 속성이 포함되지 않지만, 내부 실제 설정에는 추가될 수 있습니다.
