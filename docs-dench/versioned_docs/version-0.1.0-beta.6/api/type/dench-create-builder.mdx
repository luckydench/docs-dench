# DenchCreateBuilder

## 간략한 설명

POST와 PUT 요청을 구성하는 빌더 타입입니다. 공통 빌더 API, 실행 API, 요청 body 설정 API를 제공합니다.

## 타입 정의

```ts
interface DenchCreateBuilder<T>
  extends DenchBuilder<T, DenchCreateBuilder<T>>,
    DenchRunner<T> {
  sendJson: (data?: unknown) => DenchCreateBuilder<T>;
  sendForm: (data?: FormData) => DenchCreateBuilder<T>;
  sendBlob: (data?: Blob) => DenchCreateBuilder<T>;
  sendUrlEncoded: (data?: DenchURLSearchParams) => DenchCreateBuilder<T>;
  sendRaw: (data?: BodyInit) => DenchCreateBuilder<T>;
  api: <P = T>(api: string) => DenchCreateBuilder<P>;
}
```

### 제너릭

| Generic | Description |
| --- | --- |
| `T` | `toJson()`이 반환할 JSON 응답 타입입니다. |
| `P` | `api<P>()` 호출 시 새 빌더에 지정할 JSON 응답 타입입니다. 기본값은 `T`입니다. |

## 프로퍼티

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `sendJson` | `(data?: unknown) => DenchCreateBuilder<T>` | Yes | JSON body와 Content-Type 헤더를 설정합니다. |
| `sendForm` | `(data?: FormData) => DenchCreateBuilder<T>` | Yes | `FormData` body를 설정합니다. |
| `sendBlob` | `(data?: Blob) => DenchCreateBuilder<T>` | Yes | Blob body를 설정합니다. |
| `sendUrlEncoded` | `(data?: DenchURLSearchParams) => DenchCreateBuilder<T>` | Yes | URL 인코딩 body를 설정합니다. |
| `sendRaw` | `(data?: BodyInit) => DenchCreateBuilder<T>` | Yes | 원시 `BodyInit` body를 설정합니다. |
| `api` | `<P = T>(api: string) => DenchCreateBuilder<P>` | Yes | API 경로와 응답 타입을 변경합니다. |

`DenchBuilder<T, DenchCreateBuilder<T>>`와 `DenchRunner<T>`의 모든 프로퍼티도 상속합니다.

## 사용처

- `DenchInterface.post<T>()`의 반환 타입입니다.
- `DenchInterface.put<T>()`의 반환 타입입니다.
- POST와 PUT 요청의 body 설정 및 실행 API에 사용됩니다.

```ts
import type { DenchCreateBuilder } from 'dench-fetch';
```
