# DenchRunner

## 간략한 설명

구성된 요청을 실행하고 응답을 원하는 형식으로 반환하는 실행 메서드 인터페이스입니다.

## 타입 정의

```ts
interface DenchRunner<T> {
  toResponse: () => Promise<Response>;
  toJson: () => Promise<T>;
  toFormData: () => Promise<FormData>;
}
```

### 제너릭

| Generic | Description |
| --- | --- |
| `T` | `toJson()`이 반환할 JSON 응답의 TypeScript 타입입니다. 런타임 검증은 수행하지 않습니다. |

## 프로퍼티

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `toResponse` | `() => Promise<Response>` | Yes | 요청을 실행하고 네이티브 `Response`를 반환합니다. |
| `toJson` | `() => Promise<T>` | Yes | 요청을 실행하고 응답을 JSON으로 파싱합니다. |
| `toFormData` | `() => Promise<FormData>` | Yes | 요청을 실행하고 응답을 `FormData`로 파싱합니다. |

## 사용처

- `DenchCreateBuilder<T>`가 상속합니다.
- `DenchGetBuilder<T>`가 상속합니다.
- 모든 요청 빌더의 `toResponse()`, `toJson()`, `toFormData()` API를 정의합니다.

```ts
import type { DenchRunner } from 'dench-fetch';
```
