# 빠르게 시작하기! (Quick Start)

dench-fetch 튜토리얼에 오신 것을 환영합니다.

이 튜토리얼에서는 `dench-fetch`의 기본적인 사용법과 기능을 소개합니다. 

`dench-fetch`는 어느 환경에서든 사용할 수 있는 Fetch API의 구현체로, 빌더 패턴을 통해 HTTP 요청을 간편하게 처리할 수 있도록 도와줍니다.


## 시작하기

```bash
npm i dench-fetch
```


## 필요한 것

Node.js 20.0 이상이 필요합니다. Node.js를 설치할 때, 의존성 관련 모든 체크박스를 선택하는 것을 권장드립니다.

추가로 `dench-fetch`는 `fetch` API를 사용하기 때문에, 브라우저 환경에서는 별도의 설정 없이 바로 사용할 수 있습니다. 

Node.js 환경에서는 `node-fetch` 패키지를 설치하여 사용할 수 있습니다.
