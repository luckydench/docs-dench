## Media 쿼리

### 1. 최대 너비에 따른 미디어 쿼리
```css
@media (max-width: 600px) {
.heroBanner {
    padding: 1rem;
}
}
```
media screen 과 max-width를 쓰면 특정 너비에서의 스타일을 적용할 수 있다.
보통 모바일 너비는 600px, 태블릿 너비는 996px로 많이 사용한다.


### 2. 테마 값에 따른 미디어 쿼리
```css
@media (prefers-color-scheme: dark) {
body {
    background-color: black;
}
}
```
위 경우는 사용자의 시스템이 다크 모드를 선호하는 경우에 배경색을 검정으로 바꿔준다.

### 3. 범위 부등식을 이용한 쿼리
```css
@media (min-width: 600px) and (max-width: 1200px) {
.container {
    width: 80%;
}
}
```
위 경우는 화면 너비가 600px 이상이고 1200px 이하인 경우에 컨테이너의 너비를 80%로 설정한다.
이 방법은 특정 범위 내에서 스타일을 적용할 때 유용하다.

### 4. 화면 방향에 따른 쿼리
```css
@media (orientation: portrait) {
.container {
    padding: 1rem;
}
}
```
위 경우는 사용자의 화면이 세로 방향인 경우에 컨테이너의 패딩을 1rem으로 설정한다. 
이 방법은 화면 방향에 따라 스타일을 적용할 때 유용하다.
모바일, 태블릿 같이 화면 방향이 바뀌는 경우에 유용하다.

### 5. 지원 되는 css 문법인가에 따른 미디어 쿼리
```css
@media (hover: hover) {
.button {
    background-color: blue;
}
}
```
위 경우는 사용자의 장치가 호버를 지원하는 경우에 버튼의 배경색을 파란색으로 설정한다. 
이 방법은 호버 효과를 지원하는 장치에서만 스타일을 적용할 때 유용하다. 
데스크톱에서는 호버 효과가 일반적이지만, 모바일에서는 호버 효과가 없기 때문에 
이 방법을 사용하여 모바일에서는 호버 스타일이 적용되지 않도록 할 수 있다.
